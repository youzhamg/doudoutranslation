# 纯净双语伴读翻译扩展 (Bilingual Reader Extension)

全网视频双语字幕 + 网页逐段双语对照 + PDF 学术伴读 + 沉浸式划词/长句精听生词本。

## ✨ 核心特性

- 🎬 **全网视频双语字幕**：支持 YouTube，X/Twitter，TED 等视频，智能防抖、滚屏前缀合并、一键全轨抓取导出 SRT/TXT 字幕。
- 🌐 **网页双语伴读**：视口优先，支持动态无限加载页面（X/Twitter 等）。
- 📑 **学术 PDF 伴读**：支持本地/在线 PDF 逐段对照，集成 Gemini 伴读。
- 📖 **生词与长句精听本**：划词即搜、原生真人语音朗读、长句专属 `🎵` 音符解析，支持无限制单句复读重播与导出。
- ⚡ **双引擎智能轮换**：Google 翻译 + DeepL 免费网页通道智能熔断切换。

## 🚀 安装方式

1. 下载本仓库到本地并解压。
2. 打开 Chrome 或 Edge 浏览器，访问 `chrome://extensions/`。
3. 开启右上角的 **“开发者模式” (Developer mode)**。
4. 点击左上角 **“加载已解压的扩展程序” (Load unpacked)**，选择本项目文件夹即可。
